# 4 · Short RFC and one build step (15 min)

> **Slide recap:** the same research loop runs on local code (`structureSearch`, `localSearch`, `localFetch`), and LSP and AST find the symbol you mean, not every text match. MCP provides the actions; skills decide how to use them. Research Driven Development: plan, research, implement, and verify each step.

## Checkpoint

1. Write a short `RFC.md` from your practice 3 citation: problem, approach, one implementation step, and its check.
2. Implement only that step.
3. Run its check.

✅ **Done when** `RFC.md` cites the decision and the step passes its check, or you wrote down the blocker and the next command to run.

## Go further

Run the skills in order. Each saves its output under the workspace `.octocode/<skill>/`.

| Step | Skill | Ask for |
|---|---|---|
| A | `octocode-brainstorming` | Best practices for your tool, features similar projects have, what users ask for in issues, and what to skip. Cite every claim. Needs a web search key: see [configuration](https://github.com/bgauryy/octocode/tree/main/skills/octocode-brainstorming#configuration--web-search-keys). |
| B | `octocode-rfc-generator` | `RFC.md` built from `IDEA.md`, the plan, and the brainstorm, researching open questions instead of guessing. |
| C | `octocode-architect` | Boundaries, data flow, and change impact while you implement the RFC one task at a time. |
| D | `octocode-roast` | Issues in the implementation, ranked by impact with the code behind each. Then fix them. |
| E | `octocode-clean-agentic-code` | Dead paths, duplicates, and needless wrappers, removed without changing behavior. |

### Web search keys for brainstorming

`octocode-brainstorming` needs at least one web search key. Free tiers are enough: [Tavily](https://app.tavily.com/), [Serper](https://serper.dev/), [Exa](https://dashboard.exa.ai/). Store keys in `~/.octocode/.env`, never in the repo or the skill folder:

```bash
npx octocode config set TAVILY_API_KEY --stdin    # keeps the key out of shell history
npx octocode config check TAVILY_API_KEY          # exit 0 when set; never prints the value
npx octocode skill check octocode-brainstorming   # install and key readiness
```

The checks confirm a key is set, not that the provider accepts it. See the [brainstorming configuration](https://github.com/bgauryy/octocode/tree/main/skills/octocode-brainstorming#configuration--web-search-keys).
