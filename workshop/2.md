# 2 · Idea (10 min)

> **Slide recap:** a confident answer can be wrong. Models agree with you, reverse when pushed, and answer ambiguous questions differently. Stop trusting, start testing, and give the model the context its next step needs. A precise idea is the first piece of that context.

## Checkpoint

Create a workspace folder and add `IDEA.md`. Pick something small you would use daily: an MCP, a skill, a feature, or a feature for Octocode.

```markdown
# Idea
Problem:      <who has which pain>
What I build: <one sentence, e.g. "an MCP that helps me XYZ">
Done when:    <one observable check, e.g. "the agent answers X with a cited file:line">
Out of scope: <what I will not do today>
```

✅ **Done when** all four lines are filled and a peer could test the **Done when** line.

## Go further

Get the Octocode skills for practices 4 and 5. Clone the repo to have skills, docs, and source at hand:

```bash
git clone https://github.com/bgauryy/octocode.git
```

Or install the skills for your platform (`pi`, `cursor`, `claude`, `codex`, `opencode`, `copilot`, `gemini`, or `all`):

```bash
npx octocode skill install --all --platform claude --global
npx octocode skill check
```
