# 5 · One repeatable check (10 min)

> **Slide recap:** `clasify` asks a judge model to score candidate files so the agent reads fewer of them, but a score is not a citation: read the source before you claim. Give the critic a fresh context. Benchmark loop: measure, critique, change, repeat, and keep a held-out set, because questions you tuned on are no longer clean.

## Checkpoint

1. Write down one input for the step from practice 4 and the result you expect.
2. Run it and record the observed result.
3. Decide **keep** or **change**, and note the limit: one run is a smoke test, not proof.

✅ **Done when** the input, observed result, and keep/change decision are written down.
