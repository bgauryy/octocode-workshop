# 5 · One repeatable check (10 min)

**Deck section:** 06 Octocode V3 · **Output:** a written keep/change decision with the observed result

> **Slide recap:** `clasify` asks a judge model to score candidate files so the agent reads fewer of them, but a score is not a citation: read the source before you claim. Give the critic a fresh context. The benchmark loop is: measure, critique, change, repeat. Keep a held-out set, because questions you tuned on are no longer clean.

## Checkpoint

1. Write down one input for the step from practice 4 and the result you expect. For example: "the test command for my step exits 0" or "the agent cites the file that defines X."
2. Run the input and record the observed result.
3. Decide **keep** or **change**, and note the limit. One run is a smoke test, not proof.

✅ **Done when** the input, the observed result, and the keep/change decision are written down.
