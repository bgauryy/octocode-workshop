We built Octocode's tools to make the agent reason better, so each tool's input schema carries two fields: mainGoal and reasoning (ghSearchCode shown; packages/octocode-config/contract/tool-contract.json, ledger V5). Click 1: mainGoal, the research question. Restating it in every call keeps the agent's attention on what it is actually trying to answer. Click 2: reasoning. The agent has to write down why it needs this tool now, so it reasons before it calls. Click 3: both fields end up in the context window, so the goal and the reason stay in front of the model on later turns. Both fields are optional, up to 500 characters each. The benefit is our design intent and what we saw in use, not a measured benchmark. Next: what comes back.
