The ghSearchCode MCP input is a queries array with one to five query objects (packages/octocode-config/contract/tool-contract.json, ghSearchCode inputSchema; ledger V5). This is one valid call. Click 1: mainGoal, the research question. Click 2: reasoning, why this query advances it. Both are optional per-query fields, each at most 500 characters. Use them when the agent is following an unknown across calls; omit them for a simple lookup. They make the purpose visible again in subsequent tool context, but that benefit is a design intent, not a measured improvement here. Octocode can carry them into suggested next queries.
