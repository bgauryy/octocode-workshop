First thing I tested after I stopped trusting: prompting, and how I learned it. The three steps draw left to right. Step 1, best practices: the dair-ai Prompt Engineering Guide (https://www.promptingguide.ai/). It teaches structure, not magic words: role, task, constraints, examples, output format. Step 2, reverse-engineering the top models and tools: read the system prompts they actually ship. The github.com/asgeirtj/system_prompts_leaks archive collects them; I contributed PR #44 (https://github.com/asgeirtj/system_prompts_leaks/pull/44/changes, merged 18 Oct 2025; ledger H7), publishing Claude Code's internal tool descriptions, so the learning didn't stop in 2023. Anthropic also publishes the system prompts of claude.ai and its mobile apps, not the API, and says "This prompt is periodically updated to improve Claude's responses" (platform.claude.com/docs/en/release-notes/system-prompts; the page started on 26 Aug 2024, per simonwillison.net/2024/Aug/26/anthropic-system-prompts). That is a legal way to study how the labs prompt. Step 3: the patterns that repeat across labs: Markdown rules inside XML-tagged sections, explicit "when to use this tool", explicit prohibitions. OpenAI's GPT-4.1 guide backs the tags: "XML performed well in our long context testing" while "JSON performed particularly poorly" (developers.openai.com/cookbook/examples/gpt4-1_prompting_guide, Apr 2025). Click 4: the main areas I practiced along the way. Step-by-step: break the task into ordered steps. Chain-of-Thought: let the model reason before it answers (Wei et al., 2022). Tree-of-Thoughts: explore several reasoning branches, evaluate them, keep the best (Yao et al., 2023). Structured output: I learned to ask the agent for an exact output shape (JSON, XML, a table) so I could check and reuse it. Click 5: and I played a lot with breaking prompts, using jailbreaks and prompt-injection techniques, to see where instructions stop holding. Breaking them taught me as much as writing them. All of these are covered in promptingguide.ai. Next: that structure up close, Markdown versus XML and how they combine.
