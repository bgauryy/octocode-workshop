Left: a real empty row from localSearch, as YAML (the hint string is from the Rust runtime, local_search/leads.rs:41; query abbreviated). The point: on an empty or failed result the agent does not have to work out what to do next; the result tells it. A compiler doesn't just say "error"; it says "did you mean…?". Octocode results do the same, through four channels; press → for each branch as it draws. (1) next.*: the unread rest (next page, continue, expand); the response is incomplete without them; 31 page kinds such as nextPage, nextMatchPage, continueWindow, expandDates (counted from packages/octocode-config/contract/tool-contract.json continuationChannels on the dev build, 2026-10-12; docs/OCTOCODE_PROTOCOL.md:88-93; ledger V7). (2) hints.*: optional leads, each a ready-to-run {tool, query}: read, findCallers, findReferences, findText, viewTree… 48 lead kinds; on a successful row they appear only with extras:["hints"] (docs/OCTOCODE_PROTOCOL.md:91). (3) hints.text: a short sentence, only on empty or failed rows and only for a per-call fact (a count, a name, a ref) that no lead or error text states (docs/TOOL_DATA_CONTRACT.md:32), e.g. "No matches in 11 files searched." Every hint is written within a 120-character budget (MAX_GUIDANCE_CHARS in crates/runtime/src/response/rows.rs:44, enforced by a test; the runtime never clips). The slide shows a real one: "Nothing searched: include/exclude matched no file." (leads.rs:41, ledger V8, re-wrapped on the slide). (4) errors: the fix, not a stack trace. 120 typed errorCodes, each with the fix in words, e.g. "Run octocode auth login or set GH_TOKEN/GITHUB_TOKEN…" (gh_shared/mod.rs, ledger V8). History: v2.3.5 (24 Jun 2025, 0b2819511) added smart suggestions on empty code searches (github_search_code.ts) and a hints array in api_status_check.ts; a consolidated hints engine came in 4.0.0 (6 Aug 2025). Outside endorsement: Anthropic's "Writing effective tools for agents" (11 Sep 2025) says to "prompt-engineer your error responses"; and Claude Code warns when MCP output exceeds 10,000 tokens and caps it at 25,000 by default (code.claude.com/docs/en/mcp).
