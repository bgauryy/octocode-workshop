The map for Part 2 before we dive in: three eras, and each one solved what the last one exposed. Press → three times; each era draws onto the rail. V1 (v1→v10, June–December 2025): GitHub research over MCP. Hints appear in 2.3.5 (24 Jun 2025), the security layer — content sanitizer plus secret masking with 164 patterns — in 2.3.22 (14 Jul), bulk queries capped at 5 in 2.3.27 (21 Jul), YAML responses in 6.0.0 (24 Sep), per-tool cache TTLs in 4.0.0 (6 Aug). Tools went 14 (1.0.0) → 26 → 10 → 9 → 7 → 5 (6.0.0): fewer, sharper tools. By v10 (24 Dec 2025) the secret patterns were 259. V2 (v11→v16, Dec 2025–Jul 2026): local tools moved inside octocode-mcp (0bef8ac76, 27 Dec 2025), LSP tools (11.1.0, 10 Jan 2026), ~/.octocode/.octocoderc (11.2.2, 19 Jan), the first SKILL.md, and the first Rust crates (16.x, 18 Jun 2026). Measured: the Rust secret scan vs the JS one, same 309 patterns, 200 runs, is 20–27× faster on clean content (1 MB: 50 ms → 2.1 ms) — e1ad2d510:packages/octocode-security/README.md:14-40. V3 (v17→v20, Jul–Oct 2026): the octocode research CLI (17.0, 14 Jul 2026), astSearch (9 Sep), the octocode-native Rust engine (15 Sep), clasify (21 Sep), minimal-by-default results in v20. Measured: August campaign, 30 GitHub questions × 3 passes, blind judge — Octocode v18 CLI used 1.99× fewer characters than plain gh, 2.62× fewer than gh+Headroom, 3.21× fewer than gh+RTK, correctness 9.19–9.30 vs 8.62–9.42 (packages/octocode-benchmark/results/SUMMARY.md:28-30). Footer: first npm release 1.0.0 on 2025-06-06; 204 versions of octocode-mcp on npm across 20 majors — today v20, Oct 2026 (npm view, 2026-10-09).
