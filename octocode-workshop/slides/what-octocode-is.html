Intro · what is Octocode

Octocode researches code with evidence

An agentic toolkit finds the relevant source and cites it in the answer.

// why: agents need a reliable way to research code across public repos and orgs.
Start with why: I built Octocode because agents need a good, reliable way to research code, across public repositories and across the organizations they work in, instead of guessing from training data. The diagram builds from the middle out. First the engine: README.md:17 says "One Rust engine, two interfaces: an MCP server and the npx octocode CLI." It does search, AST and LSP navigation, the GitHub client, caching and secret redaction (ledger X2). Then the three ways in: the MCP server gives any MCP host 12 tools; the CLI gives 13 (README.md:124, "Your agent gets 12 tools over MCP and 13 in the CLI; clasify joins both when you add its key"; ledger S3). The CLI's 13 are the MCP 12 plus ghCloneRepo. The full catalog is 16: those 13, plus clasify, plus the beta-only astTopology and astRewrite (CLI-only; packages/octocode-config/contract/tool-contract.json). All of this is the dev build, 20.2.0. And skills, 13 encoded playbooks (research, architecture, RFCs, roasts, evals…), drive either one (ledger S4). Last, who asks and what it reads: your agent (README.md:17 names Cursor, Claude, VS Code, Codex and Pi) and the sources: local code, GitHub, package registries. Say the line to remember all day, from README.md:21: "Evidence, not guesses: every answer cites exact files and lines." Extra: skills are portable. agentskills.io lists 46 client products that read SKILL.md, among them Claude Code, Codex, GitHub Copilot, VS Code, Cursor, Gemini CLI, OpenCode, Goose, Kiro and pi (agentskills.io/clients, 46 entries in the client list, re-counted 11 Oct 2026; Codex is listed as "ChatGPT & Codex").
