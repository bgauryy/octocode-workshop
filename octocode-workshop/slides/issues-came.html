The issues list from the brief (ledger V23), pinned to where in the loop each one hit. Press → once per stage. (1) Calling GitHub: rate limits. Code search allows 10 requests a minute, REST 5,000 an hour authenticated (docs.github.com, ledger V13). Security: secrets in fetched code, and content that carries instructions. Invariant Labs showed a malicious public issue making a GitHub-MCP agent leak private-repo data on 26 May 2025 (ledger V16). (2) Finding the code: the two we just solved. A file on its own doesn't say where it belongs, which ghStructure answers; and a package name doesn't say where its source lives, which package search answers. Say it plainly: those two came first, and these green cards are what we already fixed. (3) Reading the result: one large file fills the window; context grows because every read stays and is re-read on every later turn; and after several tool calls the model's attention faded. (4) The answer: hallucinations, meaning confident claims with no line behind them. Outside numbers (anthropic.com/engineering/advanced-tool-use, fetched 2026-10-09): Anthropic counted five common MCP servers at "58 tools consuming approximately 55K tokens before the conversation even starts" (advanced tool use, 24 Nov 2025). Tool definitions are context too. Ask the room: which of these have you hit with your own agents? It became too heavy, and every fix that follows was context engineering.
