Lab 1: make your first evidence call

Install Octocode, connect your agent and verify one answer against its source.

# the contract, as the agent sees it npx octocode schema localSearch --view query # one call, by hand npx octocode localSearch '{"queries":[{ "path": ".", "matchString": "export function", "resultView": "matchOnly" }]}'
prompt your agent"List your Octocode tools. Which one would you use to read 20 lines of a GitHub file — and with which fields?"
done when

auth status is green, and your agent names ghGetFileContent with ranges or matchString.

Lesson: MCP and the CLI are the same engine and the same contract. schema --view query prints the self-contained query schema (OCTOCODE_CLI.md:88-91); the localSearch call is the documented form (OCTOCODE_CLI.md:75). The prompt checks tool discovery: the right answer is ghGetFileContent with ranges/matchString (descriptions.ts:45-46). Common failure: no GitHub token → the error hint tells you exactly what to run.
