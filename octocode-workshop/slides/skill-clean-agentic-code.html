The problem: agents leave duplication, needless wrappers, masked errors and gamed tests behind. This skill removes only proven redundancy, without changing behavior. Walk the pipe: Scope the cleanup: the requested paths and intended result. Inspect contracts and consumers: for a deletion, check references, entrypoints, configuration and dynamic or external use, and remember "An empty search alone does not prove absence" (SKILL.md:22). Removal justified? Yes removes; missing evidence means investigate or report the gap; a needed behavior change means describe the repair. Remove in reviewable batches. Verify affected behavior (skills/octocode-clean-agentic-code/SKILL.md:10-17, :21-24). Press → for the mechanic: "Read the diff, never the agent's summary: completion reports have claimed passing tests that never ran." (references/test-gaming.md:5). Test-gaming signals it looks for: tests with no assertion, toBeDefined-only checks, toHaveBeenCalled() with no arguments (test-gaming.md:5-12). The audit order follows measured prevalence: duplication → error masking → test integrity → scope-creep leftovers (references/agentic-defects.md:5-10). And: "Never weaken checks or widen a mask to make cleanup pass" (SKILL.md:29).
