Lab 5: write a research skill

Create a repeatable workflow that checks whether an idea already exists.

skills/idea-scout/SKILL.md description: "Use when …" steps: 1 ghSearchRepo + artifactSearch 2 read the top 2 implementations 3 verdict: exists · partial · gap node ~/.octocode/skills/octocode-skills/\ scripts/skill-review.mjs skills/idea-scout
prompt your agent"Use the octocode-skills skill to finish idea-scout: a trigger-tuned description, steps, and an output format with citations."

Then, without naming it: "Is there already an MCP server that diffs two OpenAPI specs?"
done when

The review passes, the skill fires without being named, and the verdict cites repos and packages.

Lesson: a skill encodes your research algorithm, and the description is the trigger (progressive disclosure). idea-scout is the "skill that helps search for an idea" from the brief. The review script ships with the octocode-skills skill: install it first (npx octocode skill install octocode-skills --platform claude --global); the installer copies skills to $OCTOCODE_HOME/skills/<name> (default ~/.octocode) and links them into each host, e.g. ~/.claude/skills. The real test is the second prompt: it must trigger without the name. Next: Lab 6.
