Hands-on · setup

Get your research tools ready

Install Node 24, sign in to GitHub and connect Octocode to your agent.

# 1 · Node ≥24.15, not 25/26 (or: brew install bgauryy/octocode/octocode) node -v # 2 · GitHub login — Octocode reuses gh gh auth login # or: npx octocode auth login npx octocode auth status # 3 · add to your agent claude mcp add octocode --scope user -- npx -y octocode-mcp@latest npx octocode install # any other host # 4 · the research skill npx octocode skill install octocode-research --platform claude --global
All commands from the Octocode README (README.md:40-80) and packages/octocode/README.md. Node 24.x, ≥24.15: the octocode CLI requires ^24.15.0 (packages/octocode/package.json engines) — Node 25/26 are rejected; octocode-mcp accepts ^22.22.2 || ^24.15.0 || >=26. CHECK BEFORE THE WORKSHOP: on 9 Oct 2026 npm "latest" was octocode-mcp 19.1.0 and octocode 20.1.0 while the repo is at 20.2.0 — publish 20.x or pin the version so everyone gets the tools on these slides. Homebrew installs the native binary with no Node. gh auth login is enough — Octocode reads `gh auth token` last in its token order. For Cursor/Codex/pi etc.: npx octocode install detects hosts; --platform accepts pi, cursor, claude, codex, opencode, copilot, gemini, all. Placed right after V1 so install problems surface early and get fixed over the break. Wi-fi tip: ask people to run these before the session.
