Leave this up between labs. Auth: Octocode reads env, stored credentials, keychain, then `gh auth token` (docs/AUTHENTICATION.md). Rate limits: GitHub code search is 10 requests/minute (docs.github.com); Octocode budgets it and backs off, but a room sharing one IP still hits it — pair up. Zero hits: the instructions say "empty ≠ absent until scope, spelling, ref, index are checked" (octocode-core instructions.ts); code search covers default branches of indexed repos only. LSP: the hidden lsp-server command reports server status. Exit code 6 means a page remains (instructions.ts:29). Next: Lab 2.
