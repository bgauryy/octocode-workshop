Purpose: the agent can describe the code it needs, but it cannot name the file. Without clasify it reads candidates one by one: in the ast-grep example, 54 files contain "fix", and reading them all returned 644 KB into context. With clasify, the agent sends a goal and two questions. clasify runs the search and reads for the agent, asks Jev, TypeSafe's model for typed probabilistic decisions, to judge each file, and returns scores plus the exact lines to read next (hints.read), never the bodies. fileHas plus Scout (beta) over 9 files returned 1.9 KB in 1 call. The two questions: relevant, is this file in the right area; sufficient, does this page alone answer. A score is not proof: it ranks attention, clasify never proves absence, and the agent still reads the source before citing it.
