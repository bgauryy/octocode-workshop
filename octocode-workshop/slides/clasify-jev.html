Jev by TypeSafe · typesafe.ai · still in beta
Purpose: introduce clasify, the first Octocode tool that hands a decision to a model inside it. That model is Jev, TypeSafe's model for typed probabilistic decisions, in other words classification (https://typesafe.ai/, still in beta). Without clasify, the large model reads the candidates itself: in the ast-grep example, 54 files contain "fix", and reading them all returned 644 KB into its context. With clasify, the large model sends a goal and questions; Jev judges each file and clasify returns scores plus hints.read, the exact lines to read next, never the file bodies. fileHas plus Scout over 9 files returned 1.9 KB in 1 call. The large model still decides what to read; Jev does the screening. Caveat: a score ranks attention, it is not proof. clasify never proves absence, and the agent still reads the source before citing it.
