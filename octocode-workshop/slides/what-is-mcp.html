MCP is a conversation between two programs, and its output lands in the model's context. Start with where it came from (the strip at the top): Anthropic released and open-sourced MCP on 25 Nov 2024 (anthropic.com/news/model-context-protocol). It started around July 2024 with David Soria Parra, who worked on internal developer tools at Anthropic. Claude Desktop had artifacts but "there was no way to extend it", and the IDE had the file system but no artifacts, so "what I constantly did was just copy things back and forth between Claude Desktop and the IDE… very frustrated" (Latent Space, 3 Apr 2025, latent.space/p/mcp). He saw an M×N problem (many apps × many integrations) and solved it with a protocol, modelled on LSP. He built it with Justin Spahr-Summers, "two guys in a room riffing", not a big strategy. On a16z (2 May 2025): "I'm a developer… I know how to build for this, just let me do it." Click 1, the two sides: the host is the MCP client (Claude Code, Cursor, any agent). It starts or connects to an MCP server and talks to it with JSON-RPC, over stdio for a local server or HTTP for a remote one. Any server works the same way: a database, GitHub, a browser, your own code. Click 2, initialize: the client says hello and the server answers with its capabilities and, optionally, its instructions, a short text on how to use this server. Hosts limit it: Claude Code truncates server instructions and each tool description at 2,048 chars (code.claude.com/docs/en/mcp, checked 2026-10-09). Click 3, tools/list: the server returns every tool it offers, each with a name, a description and a schema. Click 4, tools/call: the model picks a tool and fills its arguments from the schema; the server runs the code and returns content the model reads. Click 5, the point: the host adds the instructions and tool schemas into the agent's context, in the stable, cached layer near the top. The model never sees JSON-RPC, only the text the server chose to send. Every word in instructions, descriptions and results is a prompt. Background if asked: OpenAI adopts it 26 Mar 2025 (simonwillison.net/2025/Mar/26/openaidevs); donated to the Agentic AI Foundation under the Linux Foundation, 9 Dec 2025 (anthropic.com/news/donating-the-model-context-protocol…); July 2026: "Across our Tier 1 SDKs, we’re seeing close to half-a-billion downloads a month" (blog.modelcontextprotocol.io/posts/2026-07-28/).
