Lab 6: let a critic challenge the plan

Repeat the research loop until the plan has no unsupported claims.

# 1 · generator idea-scout → pick one idea octocode-rfc-generator → plan.md # 2 · discriminator, fresh session "Verify every claim in plan.md against the code with Octocode. List unsupported claims." # 3 · fix → repeat (≤3 rounds)
how to run itRun the critic in a new session each round — a /loop or a shell loop. Stop at 0 unsupported claims or 3 rounds.
done when

A plan where every claim cites code — and a count of claims removed per round.

Lesson: RDD (MANIFEST.md): separate sessions, minimal context, a Verifier attacking the Generator. The loop from the brief: idea skill → plan → critique → fix. /loop is a Claude Code feature; elsewhere use a 3-pass shell loop around your agent CLI. The payoff is the number of unsupported claims each round removes — that is what "evidence, not guesses" looks like in a plan. Next: further reading.
