Problems only on this slide; the fixes come one per slide next, and all of them together after the hallucinations slide. Press → once and the nine cards appear in the order we'll cover them. (1) Rate limits: GitHub allows 5,000 REST requests an hour authenticated and only 10 code-search requests a minute (docs.github.com; ledger V13). (2) Leaked secrets: fetched files and issues can carry credentials and instructions aimed at the agent; 2025 saw real MCP attacks of exactly this shape (ledger V16, V17). (3) No file context: search returns a path and a line, but not where that file sits in the repo. (4) Package names: an import is a name, not a location, and models hallucinate about 19.7% of package references (USENIX Security 2025, arXiv:2406.10279). (5) Too many calls: one query per tool call meant one idea per turn, and every round trip stays in the context. (6) Context grew: whole-file reads filled the window. (7) Large files: even a file the agent needs costs many tokens to read in full. (8) Large results and PRs: long outputs and big pull requests bury the one change that matters. (9) Hallucinations: confident claims with no line behind them. Next: the first two up close, rate limits and security.
