Why I built it, in my words: "help research using octocode tools", and "I needed a unified prompt for local/external workflows". Real questions cross boundaries: lspSearch finds who calls a function in my code, artifactSearch gives the package version and its release source, ghGetFileContent reads that exact ref, ghSearchHistory finds the PR that changed it. One skill, one contract, every hop carrying a precise handle (symbol:line, name@version, repo@sha, PR #). The flagship, and the evidence backbone the other skills call. The problem: agents assert code facts without proof ("nothing calls this, safe to delete"). This skill forces claim → evidence → confidence with exact anchors. Walk the pipe as it draws: FRAME the claim and CLASSIFY it (bug / feature / enhancement / unknown); MODEL the flow: entry → transformations → state → output → consumers; SEARCH/READ with the strongest handle: text search, AST, LSP, graph, or commit/PR history (an optional semantic locate via clasify comes first); PROVE with exact anchors; DECIDE or PATCH; then VERIFY, citing only checks that actually ran (skills/octocode-research/SKILL.md:12-19, :35-43). Press → for the rule: "Empty is not absent. First repair scope, filters, ref/index, and synonyms." (SKILL.md:27). Same idea one line later: a row with status error is a broken call, never absence, and "Exit 0 does not mean every row succeeded" (SKILL.md:28). Extra: repo topology comes from npx octocode graph ingest|query (SKILL.md:58); substantial results are saved under .octocode/octocode-research/<date>-<slug>.md and rendered as a local HTML page by the shared render-report.mjs (SKILL.md:85; output.md:13). Invoke: npx octocode skill install octocode-research, then ask, for example (illustrative prompt): "Who calls resolveSkillDestination? Is the --path branch safe to delete?" Hand-off: ten of the other skills route their code facts back through research; research itself hands architecture decisions to octocode-architect and still-open ideas to octocode-brainstorming (Related skills, SKILL.md).
