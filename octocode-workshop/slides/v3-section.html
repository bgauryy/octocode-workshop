Octocode V3

The CLI, Rust engine and clasify changed how the agent runs and reads research.

05
V3 is the current Octocode, source version 20.2.0 (my dev build, unreleased; npm latest is 20.1.0; Jul to Oct 2026, v17 → v20). Four new things, each with the number it bought; the tiles count up as the slide lands. Agentic CLI: a CLI made for agents (catalog on a pipe, next.* continuations, errors that name the fix); in August the Octocode v18 CLI used 1.99× fewer characters than plain gh at similar correctness (packages/octocode-benchmark/results/SUMMARY.md:28-30; X8). Rust engine: one native engine behind MCP and the CLI; the native binary starts in ~8 ms vs ~120 ms through the Node launcher (packages/octocode-native/README.md:267-270; X3). clasify + Jev: a judge model reads for the agent. In the docs' example the agent read 1.9 KB instead of 644 KB, 339× less, answer ranked first (docs/OCTOCODE_CLASIFY.md:92-95; X6). Benchmark loop: on 2026-10-09, two laps of "read the transcripts, change one thing, rerun" took Octocode to 0.79× and then 0.73× of its own characters on the same 10 questions, correctness 8.4 → 8.5 (results/lean-vs-mcp-114934-2026-10-09.md:388-395, 452-456). The same loop is where I lost a round to a disciplined gh, which I'll show you. Next: the CLI.
