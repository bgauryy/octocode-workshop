ghStructure shows what lives around a file

A file alone doesn't say where it belongs; the tree around it does.

ghStructure
// ghSearchCode:core/src/parser.ts:42

  • └─ packages/
  • └─ core/
  • ├─ src/
  • │ ├─ parser.ts ← found
  • │ ├─ types.ts
  • │ ├─ errors.ts
  • │ └─ index.ts
  • └─ tests/ parser.test.ts

  • Where it sits

    Package core, folder src/, at any ref.

  • What lives next to it

    Siblings like types.ts, and the tests/ nearby.

  • Where to read next

    The next ghGetFileContent call.

The three main tools find the repo, the line and the file; but a file on its own doesn't say where it belongs. Click 1: ghSearchCode hands us a path and a line, parser.ts. Click 2: ghStructure gives the agent visibility into the context of a file or folder: the repository tree around it at any ref (branch or commit), and what lives next to it: siblings like types.ts, errors.ts, index.ts, and a nearby tests folder. From that the agent learns where the file sits, what lives next to it, and where to read next with ghGetFileContent. Click 3: search finds the line; structure tells the agent where it is. Source: tool name from packages/octocode-config/contract/tool-contract.json (ledger V21); an early form existed in 1.0.0 (6 Jun 2025) as view_repository_structure (36f55ae3c:src/tools/contstants.ts:2-15); it became central as usage grew.
