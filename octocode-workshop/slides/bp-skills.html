This slide is about triggers, attention and context. Tools and skills don't run because they exist; they run because the agent decides to call them, and it decides from very little: "At startup, the agent pre-loads the name and description of every installed skill into its system prompt" (anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills, 16 Oct 2025). MCP tools work the same way: the model sees the tool name, description and schema and chooses. So the description is a prompt competing for the agent's attention, and it works best in one clean, unified context rather than buried among overlapping, noisy descriptions. Press → for the weak version (illustrative, not a real file): it repeats the name and never says when to use it, so the agent has no reason to pick it. Press → for the real one, octocode-research (skills/octocode-research/SKILL.md:3, wrapped and trimmed here): "Use when…" names the intent, "good for…" lists concrete tasks in the words people type. Every Octocode skill follows that shape (octocode-skills/SKILL.md:31); the description may be up to 1,024 characters "explaining the capability and relevant user intents" (skills/octocode-skills/references/frontmatter.md:8). Then test that it fires: "Check activation against realistic requests with varied phrasing, implicit intent, and near-misses that belong to neighboring skills. Fix the intent boundary rather than adding exact keyword exceptions" (octocode-skills/SKILL.md:53). Callback, don't retell it: in the October A/B, clasify was offered in 30 of 30 sessions and called 0 times (packages/octocode-benchmark/results/mcp-clasify-ab-111154-2026-10-09.md:8-15). A tool the agent never picks does nothing. Press → for the takeaway: all of this is about giving the agent the ability to ask the right questions — the right trigger, in a clean context, lets it choose the right tool and frame the right query. Tooling: `node skills/octocode-skills/scripts/skill-review.mjs &lt;dir&gt;` lints a skill; the octocode-skills skill reviews and tunes triggers.
