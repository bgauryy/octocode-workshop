Three shortcuts break the evidence chain

An empty result, a text match, and a ranking each need source verification.

  1. 01

    Empty search is not absence.Check scope, spelling, ref and index before ruling code out.

  2. 02

    A text hit is not a symbol.Use LSP to distinguish the intended function from same-name code.

  3. 03

    A Scout score is not a citation.Read the ranked source lines before making the claim.

The practice exercise gave us three easy failure points. First, an empty search row does not prove absence: repair the scope, filters, ref, index and synonyms, as the octocode-research skill says (skills/octocode-research/SKILL.md:27; ledger V8). Second, a text hit does not prove symbol identity: the exit_code example had 26 text hits for four distinct meanings, while lspSearch resolved four locations for the intended function (ledger L2; docs/OCTOCODE_PROTOCOL.md:132). Third, Scout ranks pages, but its relevance and sufficiency scores are not evidence: read the top file and cite the deciding lines (docs/OCTOCODE_CLASIFY.md:59,72-95; ledger X5,X6).
