after · queries: [ ]

Several directions in one call

ghSearchCode { queries: [

Problem 5 from the list: too many calls. Press → (before): with one query per tool call, the agent explores one idea per turn. Search for the header, wait; search the file paths, wait; try another name, wait. Every call is a round trip, and each request and result stays in the context before the next idea is tried. Press → (after): the input schema takes a queries array, so in one call the agent sends up to five queries, each with its own filters: one by content, one by file path, one by another name for the same idea. It researches from several directions at once and gets the results back together, so it decides once instead of three times. The query fields on the slide are an illustrative example of the shape; the real limit is maxItems: 5 in the live tools/list (docs/OCTOCODE_PROTOCOL.md §3.4; ledger V5, V6). Press → (numbers): batching shipped in v2.3.27 on 21 Jul 2025. Measured much later: Octocode used 80 tool calls versus 142 for an expert gh agent on the same 30 GitHub questions (lean-vs-mcp-114934-2026-10-09.md:14,56).
