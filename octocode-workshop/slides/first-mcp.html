This is the first MCP server I ever created, built for data analysts. It had only two tools. Click 1: getContext. It returned no data at all, only method: best practices for how to be a good analyst, which I wrote together with AI. Click 2: executeQuery. Its input was described simply as SQL to execute, and it returned the rows or the error. With just that, the agent wrote sensible queries, and when one failed it read the error and fixed the query itself. Click 3: the lesson. The descriptions and the schemas were how I communicated with the agent and steered it. That is the seed of Octocode's server instructions and hints, which still open every session today.
