The message here is simple: we started moving workflows into skills. From the brief: "Octocode started to be my own toolkit, and I was missing important stuff: my own skills." I kept typing the same workflow into my agent, so each one became a skill (speaker's one-liners, ledger K2). A skill is a folder: SKILL.md plus optional references/ and scripts/, loaded only when its description matches the request (claude.com/blog/skills, 16 Oct 2025; open standard at agentskills.io since 18 Dec 2025, ledger K1). 13 ship in skills/ (ledger S4); the 12 chips are the ones we cover, and only agents-communication is out of scope today. Research is the hub every other skill routes its code facts through. Press → for install: `npx octocode skill install <name>|--all --platform …` (packages/octocode/README.md:24,104; ledger K3). The installer copies each skill once into ~/.octocode/skills/<name> and symlinks it into each host's folder: pi, cursor, claude, codex, opencode, copilot, gemini (packages/octocode-skill-installer/src/index.ts:52-99). Every skill saves its results under .octocode/<skill-name>/ and can render one local HTML report (skills/README.md:5-7).
