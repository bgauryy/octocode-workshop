The problem: a single agent anchors on its first idea and then argues for it. This skill splits the thinking across independent researchers and reconciles them by evidence quality. Walk the pipe: Frame the decision and constraints; Assign independent questions; Subagents run in parallel (the diagram's roles are promising approaches, alternatives and the current landscape, and objections and failure cases); Verify sources, freshness and counterevidence; Compare each direction, then Recommend, or loop to a targeted follow-up when a deciding gap remains (skills/octocode-brainstorming/SKILL.md:10-25). "Each worker investigates a different direction, not the same query under another label" (SKILL.md:33), and "Never report sequential passes as separate agents" (:41).
